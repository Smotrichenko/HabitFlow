# 🏆*HabitFlow*
HabitFlow — это backend-часть SPA-приложения для трекинга полезных привычек по методологии книги «Атомные привычки» Джеймса Клира.
Проект реализован на Django и Django Rest Framework и предоставляет API для управления привычками, пользователями и системой уведомлений через Telegram.
Клиентская часть предполагается в виде SPA-приложения, взаимодействующего с сервером через JSON.

## *Описание*
Backend-часть SPA-приложения трекера привычек с поддержкой:
- JWT-аутентификации
- разграничения прав доступа
- пагинации
- пользовательских валидаторов бизнес-логики
- интеграции с Telegram
- асинхронных задач Celery
- периодических задач Celery Beat
- Swagger-документации
- покрытия тестами ≥ 80%

## ⚙️*Локальный запуск проекта*
1️⃣ Создать файл .env в корне проекта:
```
SECRET_KEY=your_secret_key
DEBUG=1
REDIS_URL=redis://localhost:6379/0
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
```

2️⃣ Установить зависимости
```
poetry install
```

3️⃣ Выполнить миграции
```
python manage.py makemigrations
python manage.py migrate
```

4️⃣ Запустить сервер
```
python manage.py runserver
```
Backend будет доступен по адресу:
```
http://127.0.0.1:8000/
```

## 👤*Пользователи*
Пользователь может:
- зарегистрироваться
- авторизоваться по JWT
- просматривать свои привычки
- создавать привычки
- редактировать свои привычки
- удалять свои привычки
- просматривать публичные привычки других пользователей

**Каждый пользователь имеет доступ только к своим объектам.**

## 📌*Привычки*
Модель Habit включает:
- Пользователь (владелец)
- Место выполнения
- Время выполнения
- Действие
- Признак приятной привычки
- Связанная привычка
- Периодичность (1–7 дней)
- Вознаграждение
- Время выполнения (≤ 120 секунд)
- Признак публичности

## 🧠*Бизнес-правила (валидаторы)*
Реализованы следующие ограничения:
- Нельзя одновременно указывать вознаграждение и связанную привычку
- Время выполнения не может превышать 120 секунд
- Связанной может быть только приятная привычка
- У приятной привычки не может быть вознаграждения или связанной привычки
- Периодичность выполнения: от 1 до 7 дней

## 📄*Пагинация*
Список привычек возвращается с пагинацией:
- 5 привычек на страницу
- стандартная DRF-пагинация (count, next, previous, results)

## 🔔*Telegram интеграция*
Сервис отправляет напоминания пользователю через Telegram-бота.
Необходимо:
- Создать бота через @BotFather
- Указать TELEGRAM_BOT_TOKEN в .env
- Привязать telegram_chat_id к пользователю

Напоминания отправляются асинхронно через Celery.

## ⚡*Celery*
Запуск Redis
```
redis-server
```
Запуск Celery Worker
```
celery -A config worker -l INFO
```
Запуск Celery Beat
```
celery -A config beat -l INFO
```
Что делает Celery:
- Проверяет привычки каждую минуту
- Если текущее время совпадает с временем привычки — отправляет уведомление в Telegram
