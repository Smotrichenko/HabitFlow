# 🏆**HabitFlow**

## 📋 *Описание*
HabitFlow — backend-сервис для трекинга привычек, построенный на Django REST Framework.

Проект реализует API для управления привычками, пользователями и уведомлениями, включая JWT-аутентификацию, асинхронную обработку задач через Celery, интеграцию с Telegram и систему бизнес-правил для формирования полезных привычек.

Проект демонстрирует ключевые backend-сценарии: работу с API, авторизацией, асинхронными задачами, внешними интеграциями и бизнес-логикой.


## 🚀 *Основные возможности*
- регистрация и аутентификация пользователей (JWT)
- CRUD для привычек
- настройка расписания выполнения привычек
- система бизнес-ограничений (валидаторы)
- асинхронная отправка уведомлений через Celery
- периодические задачи через Celery Beat
- интеграция с Telegram-ботом
- API-документация через Swagger
- пагинация и фильтрация данных
- покрытие тестами (pytest)

## 💡 *Какую задачу решает проект*
HabitFlow помогает пользователю формировать полезные привычки:
- позволяет создавать и отслеживать привычки
- задавать регулярность выполнения
- получать напоминания через Telegram
- соблюдать ограничения, направленные на формирование эффективных привычек


## 🔔 *Сценарий использования*
1. Пользователь регистрируется и получает JWT-токен
2. Создаёт привычку с параметрами (время, периодичность, условия)
3. Система проверяет бизнес-ограничения
4. Celery Beat отслеживает время выполнения
5. При наступлении времени привычки отправляется уведомление через Telegram
6. Пользователь выполняет привычку


## 🧠 *Бизнес-логика и ограничения*
В проекте реализованы правила:
- нельзя одновременно указывать вознаграждение и связанную привычку
- связанной может быть только приятная привычка
- у приятной привычки не может быть вознаграждения или связанной привычки
- время выполнения привычки ограничено 120 секундами
- периодичность выполнения — от 1 до 7 дней

## ⚙️ *Установка и запуск проекта*
1. Клонировать репозиторий
```
git clone git@github.com:Smotrichenko/HabitFlow.git
cd HabitFlow
```
2. Установить зависимости
```
poetry install
```
3. Настроить переменные окружения
```
создать .env файл и указать параметры БД, Redis и Telegram-бота.
```
4. Выполнить миграции
```
python manage.py makemigrations
python manage.py migrate
```
5. Запустить сервер
```
python manage.py runserver
```
6. Запустить Celery worker
```
celery -A config worker -l info
```
7. Запустить Celery Beat
```
celery -A config beat -l info
```
